# The upstream Rocq libraries the vendored signature stub in `rocq-stub/`
# mirrors, and the proof-mode `.v` this crate emits is type-checked against.
#
# Two libraries, with very different exposure:
#
#   coq-wasm / WasmCert-Coq -- PUBLIC (https://github.com/WasmCert/WasmCert-Coq).
#     Both the tag and the commit it resolves to are recorded, because a tag can
#     be moved and a commit cannot. `rocq-stub/wasm/` mirrors its
#     `theories/{datatypes,bytes,numerics,host}.v`. Needing no credential, this
#     half runs in CI.
#
#   wasm-verifier -- PRIVATE. `rocq-stub/wasm_verifier/` mirrors its
#     `theories/{Assertions,Verifier,Exists}.v`. This half runs only where a
#     checkout exists, which in practice means a developer machine.
#
# `tests/src/rocq_stub_drift.rs` reads the sources AT THE REVISIONS BELOW with
# `git show`, so a checkout parked on another commit cannot change the verdict.
#
# WHY THIS FILE CARRIES DIGESTS AND NOT CONTENT
# ---------------------------------------------
# wasm-verifier's reciprocal pin (`book/inference-pin.txt` there) commits the
# cited Inference source lines verbatim. That is safe in the direction it runs:
# a public repository's text recorded inside a private one. The reverse would
# publish private library source from a public repository, so the narrowing
# direction commits SHA-256 digests instead. A drift shows up as a digest that
# no longer matches, and the differing names are printed at failure time from
# the developer's own checkout -- never written here.

# The Coq standard library names the stub re-declares locally rather than taking
# from upstream. Each is an exemption from the existence direction, and each
# claims something checkable: that the name is bound by Coq's own standard
# library, so the pinned upstream library has no obligation to declare it.
#
# `list_byte_of_string` is `Stdlib.Strings.Byte.list_byte_of_string`. WasmCert
# uses it (`String.list_byte_of_string` in its `operations.v` and its binary
# format parser) without re-exporting it, and the stub must declare it because
# it declares its own opaque `byte` for the emitted `Mi`/`Me` helpers to build
# import and export names with.
#
# An exemption that stops being needed is itself a failure: the drift check
# rejects a name listed here that upstream does declare, so this list cannot
# quietly grow into a blanket.
stdlib-name list_byte_of_string

# One line per logical module: the SHA-256 of the REAL-ONLY declaration set --
# the names the upstream module binds and the stub does not -- followed by that
# set's size. The digest is taken over the sorted names joined by "\n". The
# names themselves are never written here.
#
# This is the narrowing direction. The stub is a deliberate narrowing of two much
# larger libraries, and the fiction direction alone cannot see that: it only asks
# whether what the stub says is true, never whether upstream grew a declaration
# the stub should have mirrored or dropped one it was narrowing away from. A
# changed digest means the narrowing itself moved and wants a human to look.
#
# Regenerate after a deliberate pin bump:
#
#   INFERENCE_ROCQ_DRIFT_UPDATE=1 cargo test -p inference-tests rocq_stub_drift::
#
